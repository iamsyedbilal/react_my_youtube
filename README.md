# React YouTube Clone

A YouTube clone built with React and the YouTube Data API v3. Search for videos, watch them with an embedded player, and switch between dark and light mode.

**Live Demo:** [react-my-youtube.vercel.app](https://react-my-youtube.vercel.app)

## Features

- Video search using YouTube Data API v3
- Embedded video player
- Related videos sidebar
- Dark / light mode
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

```bash
VITE_YOUTUBE_API_KEY=your_youtube_api_key
```

Get your API key from [Google Cloud Console](https://console.cloud.google.com)
